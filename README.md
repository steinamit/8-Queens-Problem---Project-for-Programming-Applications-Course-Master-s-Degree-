# Eight Queens Solver

> Recursive backtracking that finds all 92 solutions to the eight queens puzzle.

![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white)

## Highlights

- Finds and prints all 92 solutions with run time.

## How it works

`Legal_place` checks columns and diagonals, `solve` places queens row by row and backtracks on conflict, and each solution prints as an 8×8 board.
